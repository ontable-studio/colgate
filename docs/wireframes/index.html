Spesifikasi layout (untuk Oji dan Irsal)

Hal Nilai
Kanvas desain 1080 × 1920 px (portrait). Ekspor aset @2x (2160 × 3840) agar tajam di 4K.
Safe area 80 px dari tiap sisi (garis titik di wireframe). Teks dan tombol penting tidak boleh di luarnya (bezel TV bisa memotong).
Ukuran sentuh Tombol minimal 160 px tinggi, jarak antar tombol minimal 40 px.
Font Colgate Ready (Bold/Light), Myriad Pro sebagai cadangan. Teks isi minimal 44 px.
Warna Merah Colgate + gradient merah gelap radial, aksen oranye-emas, putih (sesuai brand).
Format aset PNG/WebP RGB transparan per elemen. Bukan PSD/AI/CMYK.
Animasi (kapsul, keranjang) Sprite statis dulu. Efek (kilau, partikel) dibuat di kode agar ringan.

  • Timer tetap atau game berakhir saat meter penuh? (layar 3)
  • Teks klaim/disclaimer final dan pesan kampanye. (layar 1, 6)
